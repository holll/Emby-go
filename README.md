# Emby-go 用户手册

Emby-go 是给 **AV / FC2 类 NFO + `.strm` 媒体库** 用的轻量媒体库服务端：你把整理好的影片目录挂进来，用 Emby 客户端（或浏览器）观看海报墙；播放时服务端只做 **302 跳转**到网盘/远端真实链接，零带宽、不转码。

## 快速上手

1. **准备媒体目录**：每部影片一个文件夹，内含同名 `.strm`（内容为一行 `http(s)://` 链接）+ 同名 `.nfo` 元数据，海报可放 `poster.jpg` / `landscape.jpg` / `fanart.jpg`（也认 `folder.jpg`/`cover.jpg`）。只有 `.strm` 没有 NFO 的条目会进「待补录」，不会出现在影视列表里。
2. **启动服务**：下载 Release 二进制或 `go build -o metatube ./cmd/metatube`，复制 `config.example.yaml` 为私人 `config.yaml`，填好 `setup_code`（随机字符串，首次初始化必填）和端口后运行 `./metatube -c ./config.yaml`。同机浏览器打开 `http://127.0.0.1:18080/` 创建管理员（账号 ≥3 字符、密码 ≥9 字符）。
3. **建媒体库**：后台「媒体库」登记服务器上的绝对目录路径，点扫描等进度完成，在「媒体墙」确认影片已入库。
4. **用客户端看**：Emby 客户端连接同一地址（或 `http://<host>:18080/emby`），用管理员账号登录即可浏览、续播、收藏。浏览器也可点海报直接播放，但请注意下面的限制。

## 媒体目录约定

```
ABF-018/
├── ABF-018.strm      # 一行 http(s):// 链接
├── ABF-018.nfo       # 元数据：标题/流派/演员/合集等
├── poster.jpg        # 可选主海报
├── landscape.jpg     # 可选宽图
└── fanart.jpg        # 可选背景图
```

- 扫描时 `http/https` + NFO → 可播放；`http(s)` 无 NFO → 待补录；`ed2k` 等其它 scheme → 不兼容，不进 Emby。
- 图片直接引用已有文件，不做格式转换（`webp/jpg/jpeg/png` 皆可）。库封面取库根 `poster`→`folder`→`cover`→`default`，没有就借库内最近入库影片的图。
- **多分段**：同目录同名基名带 `-CD<数字>` 的 `.strm` 算一部片（如 `Split-CD1/CD2/CD3`），CD1 为主，CD2+ 作分段，列表里只占一位。
- **合集**：NFO `<set><name>` 自动聚合，Views 里会出现「合集」。

## 扫描

后台可跑**增量扫描**（万级库默认、推荐）或**全量重建**；两者都会完整枚举目录，区别只在工作量：

- 增量：核对 `.strm`/NFO 摘要与持久指纹，没变化的影片组跳过，不解析 NFO、不重写、不推版本，万级库日常定时扫很快。
- 全量：重建全部索引；图片被同大小同时间原地替换时增量可能识别不到，这时改改文件时间或跑一次全量。
- 扫描中失败会保留已成功部分的结果；空库删除需手动确认，不会自动清。重扫失败不要重复整理同一批。

升级前先停服并自行复制数据库文件（默认 `data/emby.db`）及配置、人工 NFO 和图片；正常退出后再复制，回退必须恢复升级前的整套匹配副本，不能仅更换旧二进制。数据库含密码与 API 密钥摘要，副本应私密存放。`reindex` 始终全量。

## 播放

- 媒体墙点海报用内置 ArtPlayer 播放，Emby 客户端同样走 `/Videos/{id}/stream` **302 直拉**，服务端零带宽。
- **浏览器无法代理**：HTTPS 后台 + HTTP 源站会被浏览器混合内容/跨域拦截；H.265/MKV 等浏览器不支持的编码也播不了。这两类情况请用 Emby 客户端。
- Emby 客户端能直连源站、支持对应编码即可播放；服务端不转码。
- 「在線播放」只在媒体墙内有效；外部客户端请走 Emby 协议入口。

## Emby 客户端接入

```
服务器地址：http://<host>:18080          # 或 http://<host>:18080/emby
账号/密码：  初始化时创建的管理员
```

已对齐的主链路：登录 → Views（库 + 合集）→ 最新/续播/推荐 → 影片列表（排序/过滤/分页/搜索）→ 详情/图片 → 相似推荐 → 播放信息 → 302 播放 → 进度/收藏/评分上报。

普通用户默认没有媒体库授权，看不到内容；请管理员在后台给账号授权。图片端点匿名公开（兼容浏览器 `<img>`），私密性不等于影片详情，敏感海报请别放。

第三方程序可用后台生成的 **Emby API 密钥**接入 Emby 兼容接口；密钥不等同管理员，访问 `/api/admin/*` 等管理面一律 403。

## 管理后台

`http://127.0.0.1:18080/admin`（**仅管理员**能登录）提供：

- 总览统计与「服务状态」面板（版本、监听地址、数据库、缓存、任务与计划任务、图片缓存等只读证据）、媒体库管理（封面卡片网格）、扫描/重建进度
- 媒体墙（海报墙 + 无限滚动 + 播放；筛选/搜索/排序/重读/删索引）
- 刮削（批量/单条预览确认/头像）与影片编辑（待补录也可入编辑链）
- 仅翻译（见下）、Emby API 密钥、任务/运行日志、防火墙、设置
- 防火墙把 IP 黑名单、登录记录（分页 + 按 IP/结果筛选 + 一键拉黑）和播放记录（同用户同影片合并、分页）放在一页。
- 设置分账户与安全、用户与授权、通知、日志与保留、图片缓存、索引恢复；计划任务、刮削连接与策略默认收起，按需展开即可。

窄屏（手机/平板）用抽屉菜单，触控目标至少 44px。**改了源码要重新构建并重启二进制，再刷新后台**才生效。

### 刮削（MetaTube）

在影片详情打开单条刮削预览，可改搜索条件，不用先改 NFO：

| 方式 | 标题/番号/URL | MetaTubeId |
| --- | --- | --- |
| 常规搜索 | 番号或搜索词 | 留空 |
| 指定源 | 番号或搜索词 | 源名称 |
| 精准 ID | 可留空 | `Provider1:movie-id`（源站固定 ID，不是番号） |
| 精准 URL | 完整影片源链接 | 留空 |

搜到候选看详情与差异，点「确认写入」才落盘；搜索和预览不写文件、不翻译、不下图。命中后 NFO 会存 `<uniqueid type="metatube">` 标记，后续自动预览复用它；标记或源失败不会静默换搜，可手动改条件重搜。写入遵守「只补缺失/覆盖」与字段锁。

### 仅翻译

可独立于刮削执行：选单片或批量翻译，或建「独立翻译」计划任务。默认只翻标题（读 `<originaltitle>`）；简介翻译要显式勾选（当前 `<plot>` 可能已是译文）。只改选中非空字段，不重抓元数据/图片；失败不覆盖原文；取消只停后续，不回滚已完成。

### 字幕标记整理

影片详情维护区「字幕标记整理」：先看证据与拟提交，再确认。不需 MetaTube，不翻译/探测/下图，只处理单片现有 STRM/NFO。默认只补缺失，有标签或锁受保护；依据变化要重新预览；部分成功时归属失败需人工核对（重扫救不回归属）。

## 配置（config.yaml）

最常用几项，完整示例见 [config.example.yaml](<config.example.yaml>)：

```yaml
port: 18080               # 监听端口（数字）
debug: false              # true 开启原始请求调试日志，仅临时排障，改后重启
db_path: "emby-go.db"     # SQLite 文件
server_name: "Emby-go"    # 对外站名
setup_code: ""            # 首次初始化验证码，公网必填随机值
redis_addr: ""            # 可选 Redis；留空/不可达自动回退进程内缓存（仅单实例）
session_ttl_days: 30      # 会话有效期天，0=不过期
```

`port` 只接受数字、绑定全部网卡，不能绑回环；`server_id` 首次启动自动生成并写回配置保持稳定。改配置后重启服务。

### 调试日志

`debug: false` 时普通请求日志仍原样记录请求 URI（路径、query、转义均保留，**`api_key`/`token` 不再隐藏**），只跳过高频图片/静态/流请求。`debug: true` 额外记录非敏感头、预算内非敏感路由请求体、错误与 panic 堆栈；Authorization/Cookie/X-Emby-Token 等敏感头仍遮盖，认证/改密/密钥等敏感路由请求体不读不记。

> **危险**：日志和探针可能含 URL 内凭据。不要把日志导出到公开 issue/Git/聊天；排障后改回 `debug: false` 并重启，旧日志不会自动删除，若已泄漏请轮换凭据。

### 日志保留

设置 → 日志保存期限 0–3650 天，`0` 默认不清理，建议 7–30 天。非零保存需确认，立即清过期 app/request 日志。

### Webhook（SmartStrm 联动）

默认关闭。后台「设置 → Webhook 多目标」最多配 10 个，每个独立订阅 13 类事件、编码、超时。保存整集合原子生效。缺省只订阅删除：**管理员明确删除单部影片且提交成功**才发 `item.deleted`（`.strm` 绝对路径），扫描清理/重建不发。

> **危险**：SmartStrm 收到 `.strm` 路径会删整个远端文件夹，可能含其它影片。先用独立测试目录核对再上真实收藏，不要盲目重发（超时也可能已删）。

## 部署

### Linux 原生（systemd）

```bash
sudo ./deploy/install.sh              # 下载最新 Release 并注册服务
sudo EMBY_GO_VERSION=v2.2.7 ./deploy/install.sh   # 指定版本
```

程序装到 `/opt/emby-go/emby-go`，配置 `/etc/emby-go/config.yaml`（已有不覆盖），由 [deploy/emby-go.service](<deploy/emby-go.service>) 模板启动，[deploy/install.sh](<deploy/install.sh>) 负责下载验证。Release 只发布二进制和 SHA256SUMS，部署脚本与 Service 模板只在仓库中，不随包发布。管理员在后台左下角点版本号可检查更新，确认后服务端下载、校验 SHA256SUMS、执行 `-version` 核对、原子替换、重启；**无自动回退**，替换后起不来需手工处置。缺 SHA256SUMS 即报错停止。

TLS 由 Nginx/Caddy 终止，本服务不内置 TLS。公网前必设 `setup_code` 或 `initialize_allow_from`；默认不信任 `X-Forwarded-For`，要信任代理须配 `trusted_proxies`。SQLite 单实例，不要多实例共享同一库。

媒体库写权限要在存储侧允许 root 写，并用 `sudo systemctl edit emby-go` 追加 `ReadWritePaths=/srv/media`（替换为真实路径）。`ffprobe` 可选（媒体信息探测用），Debian/Ubuntu `sudo apt-get install ffmpeg`。

## 常见问题

- **扫不到影片**：确认 `.strm` 内是 `http(s)://` 一行且同名 `.nfo` 存在；无 NFO 的只进待补录不进 Emby。
- **浏览器播不了**：多为混合内容或编码不支持，改用 Emby 客户端。
- **客户端搜不到/续播空**：先确认账号已授权媒体库；普通用户默认无授权。
- **图片不显示**：确认目录里有 `poster.jpg`/`landscape.jpg`/`fanart.jpg`（或 `folder/cover`），扫描不转码。
- **日志里看到密钥**：URL 原样记录所致，关 `debug`、轮换凭据，别外传日志。

## 范围与不做

仅 `http(s)-strm` 直拉，不做转码/HLS/直播/音乐/通用插件（内置 MetaTube 除外）。源码入口见 [cmd/metatube](<cmd/metatube>)。
